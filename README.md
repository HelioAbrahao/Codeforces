# Codeforces – Soluções

Repositório com minhas soluções para problemas do [Codeforces](https://codeforces.com/profile/helioabrahao007), organizadas para treino de lógica de programação e preparação para maratonas.

## Objetivo

- Treinar lógica de programação e resolução de problemas
- Aprimorar conhecimentos em C++ (e eventualmente Python)
- Manter um histórico de evolução ao longo do tempo

## Organização

O repositório segue duas convenções:

- **Problemas individuais**: nomeados diretamente com o título do problema (ex: `Watermelon.cpp`, `Pangram.cpp`)
- **Contests e maratonas**: quando participo de uma competição específica, crio uma subpasta com o nome do evento (ex: `Codeforces Round 1062 (Div.4)/`), agrupando os exercícios resolvidos nela

Essa estrutura mistura soluções avulsas com competições completas, então nem todo arquivo pertence a uma pasta — arquivos soltos na raiz são exercícios resolvidos fora do contexto de um contest específico.

## Linguagens utilizadas

- **C++** (principal)
- **Python** (eventualmente)

## Como compilar e rodar (C++)

```bash
g++ -std=c++17 -o nomeDoArquivo nomeDoArquivo.cpp
./nomeDoArquivo
```

# Codeforces – Solutions

Repository with my solutions to [Codeforces](https://codeforces.com/profile/helioabrahao007) problems, organized for practicing programming logic and preparing for competitive programming contests.

## Goal

- Practice programming logic and problem-solving
- Improve C++ skills (and occasionally Python)
- Keep a record of progress over time

## Organization

The repository follows two conventions:

- **Individual problems**: named directly after the problem title (e.g., `Watermelon.cpp`, `Pangram.cpp`)
- **Contests and marathons**: when I take part in a specific competition, I create a subfolder named after the event (e.g., `Codeforces Round 1062 (Div.4)/`), grouping the exercises solved in it

This means loose files and full contests coexist in the repo — files at the root are problems solved outside the context of a specific contest.

## Languages used

- **C++** (primary)
- **Python** (occasionally)

## How to compile and run (C++)

```bash
g++ -std=c++17 -o fileName fileName.cpp
./fileName
```

## Notes

- Solutions are for educational purposes and reflect my reasoning at the time — they may be improved later
- File names may have small inconsistencies (e.g., variations like `Elephant.cpp` / `Elephant2.cpp`) when I revisit a problem
